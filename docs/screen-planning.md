# Presentation Layer

The Presentation Layer manages all user interactions, displays pages, captures user input, and provides feedback based on user roles.

---

## Shared Features

These features are available to all authenticated users:

* Login and authentication system
* Profile management page
* Notifications system
* Navigation bar based on user role
* Logout functionality

---

## Public User Screens

### Screens

1. Home Page
2. Report Bee Case Page
3. Report Status Tracking Page

### Functionalities

* Submit bee rescue reports
* Upload bee/swarm images
* Add location and description
* Track report status

---

## Volunteer Screens

### Screens

1. Volunteer Dashboard
2. Available Missions Page
3. Mission Details Page
4. Map View
5. Notifications Page

### Functionalities

* View nearby rescue missions
* Accept missions
* Update mission progress
* Upload rescue result images
* View mission locations on map

---

## Coordinator Screens

### Screens

1. Coordinator Dashboard
2. Case Management Page
3. Assign Volunteer Page
4. Notifications Center
5. Statistics Page

### Functionalities

* Review and manage reports
* Assign volunteers to missions
* Track mission progress
* Send notifications to volunteers
* Monitor rescue operations

---

## Admin Screens

### Screens

1. Admin Dashboard
2. User Management Page
3. Reports Archive
4. Analytics & Statistics Page
5. System Settings Page

### Functionalities

* Manage users and permissions
* View system analytics
* Edit or remove reports
* Configure system settings
* Monitor overall system activity
